Attention Is All You Need

A landmark paper that introduced the Transformer architecture — replacing RNNs and CNNs entirely with self-attention. It redefined sequence modeling and became the foundation of every modern LLM.

Core contribution
The Transformer is the first sequence transduction model based entirely on self-attention — dispensing with recurrence and convolutions. This enables massive parallelization and superior long-range dependency modeling.
Before: RNNs / LSTMs processed tokens sequentially — slow to train, hard to parallelize, struggled with long-range dependencies.
After: Transformers process all tokens simultaneously using attention — highly parallel, scales with more compute, attends to any position directly.

Architecture detail

Multi-head attention

Instead of one attention function, the paper runs h parallel attention heads, each in a lower-dimensional projection. This lets the model jointly attend to different subspaces.

Multi-head formula
MultiHead(Q,K,V) = Concat(head₁,...,headₕ) · Wᴼ
headᵢ = Attention(Q·Wᵢᴼ, K·Wᵢᴷ, V·Wᵢᵛ)

Paper uses h=8 heads, d_k=d_v=d_model/h=64. Total compute is similar to single-head full-dim attention.

No recurrence — need position

Positional encoding

The Transformer has no inherent sense of order. Positional encodings are added to token embeddings so the model can learn to use sequence position.

Sinusoidal functions
PE(pos, 2i) = sin( pos / 10000^(2i / d_model) )
PE(pos, 2i+1) = cos( pos / 10000^(2i / d_model) )

Each position gets a unique signature across d_model dimensions. The wavelengths form a geometric progression from 2π to 10000·2π.

Model design

Transformer architecture

The Transformer follows an encoder–decoder design. Both sides use stacked self-attention and feed-forward layers with residual connections and layer normalization.

Three types of attention in the Transformer
Encoder self-attention — all keys, values, and queries come from the encoder's previous layer. Every position can attend to every other position.
Decoder masked self-attention — like encoder self-attention, but positions can only attend to earlier positions (mask sets future positions to −∞ before softmax). Preserves auto-regressive property.
Cross-attention (encoder-decoder) — queries come from the decoder; keys and values come from the encoder output. Allows every decoder position to attend over the full input sequence.

Theoretical analysis

Complexity analysis

Why self-attention? The paper compares self-attention to recurrent and convolutional layers across three key metrics.

Table 1 from paper — layer complexity comparison
Layer type Complexity / layer Sequential ops Max path length
Self-attention O(n² · d) O(1) O(1) ★
Recurrent O(n · d²) O(n) O(n)
Convolutional O(k · n · d²) O(1) O(log_k n)
Self-attn (restricted) O(r · n · d) O(1) O(n/r)

n = sequence length, d = representation dim, k = conv kernel size, r = restricted attention neighborhood size

Why path length matters
In RNNs, to relate token 1 to token n, the signal must traverse n steps forward and backward — the gradient path is O(n). This makes it hard to learn long-range dependencies.
In self-attention, any two positions are connected in a single operation — path length O(1). The model can directly compare "the" at position 1 to "mat" at position 6 with equal ease as adjacent tokens.
